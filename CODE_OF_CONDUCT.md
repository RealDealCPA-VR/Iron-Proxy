# Code of Conduct

Be kind, be direct, assume good faith. Harassment, discrimination and personal attacks are not welcome anywhere in this project: issues, pull requests, discussions or commits.

Maintainers may edit, remove or lock content that violates this, and may block repeat offenders. To report a problem, use GitHub's report feature or contact the maintainers through the organisation profile.

This is a condensed statement in the spirit of the Contributor Covenant 2.1.
